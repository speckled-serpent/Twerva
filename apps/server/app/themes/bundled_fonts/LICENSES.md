# Bundled theme fonts

These files ship inside the `app.themes` package so render, measure, and
preview use the same faces the font dropdown offers. Prod does not install
extra system font packages. Each family is the SIL Open Font License 1.1.
The `OFL.txt` next to the files is the license copied from Google Fonts.
Reserved Font Names stay with the upstream project; these files are unmodified.

Weight and bold on a variable font set the `wght` axis. Italic uses the
italic file when this catalog includes one. A family with no italic file
keeps that family's roman cut. Pacifico is a single regular file, so bold
and italic stay that cut.
