# Twerva ops

Vite + React + TypeScript stub for the Twerva ops console. No product loop yet.

Requires **Node.js 20+** (22 is fine).

## Run locally

From this directory:

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173). The page should read **Twerva ops console stub**.

## Production build

```bash
npm run build
npm run preview
```

`npm run build` type-checks with `tsc -b`, then writes static files to `dist/`.
